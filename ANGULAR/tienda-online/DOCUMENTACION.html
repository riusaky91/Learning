SECCIÓN I: USUARIO FINAL

Introducción a la Aplicación

Tienda Online es una aplicación web moderna y segura que permite gestionar un catálogo de productos con sistema de autenticación integrado.

Ventajas Principales
  • Interfaz intuitiva: Diseño limpio y fácil de usar
  • Seguridad: Sistema de autenticación con credenciales personales
  • Acceso rápido: Carga rápida de contenidos
  • Responsivo: Compatible con dispositivos móviles y escritorio
  • Confiable: Respaldado por tecnología Firebase

Inicio Rápido

Primer Acceso: Solicita credenciales al administrador de la tienda.
Pasos:
  1. Abre tu navegador web
  2. Navega a: http://localhost:4200/
  3. Ingresa tus credenciales
  4. ¡Bienvenido a Tienda Online!

Funcionalidades Principales

Panel de Inicio: Bienvenida personalizada y accesos rápidos a secciones principales
Listado de Productos: Visualiza, busca, edita y elimina productos del catálogo
Agregar Producto: Formulario para añadir nuevos artículos con validaciones
Editar Producto: Modifica información de productos existentes
Acerca De: Información sobre la tienda y contacto
Utilidades: Calculadora, alertas y ejemplos interactivos

Sistema de Autenticación

Login
  1. Ingresa tu correo electrónico
  2. Ingresa tu contraseña
  3. Haz clic en "Iniciar Sesión"
  4. Serás redirigido automáticamente al panel principal
Logout
  1. Localiza el botón "Logout" en la barra superior
  2. Haz clic para cerrar tu sesión
  3. Serás redirigido a la página de login

Preguntas Frecuentes

P: ¿Olvidé mi contraseña?

R: Contacta al administrador de la tienda para resetear tu contraseña.

P: ¿Se guardan mis productos si cierro sesión?

R: Sí, todos los productos se guardan en la base de datos Firebase automáticamente.

P: ¿Cuántos productos puedo agregar?

R: No hay límite, puedes agregar tantos productos como necesites.

P: ¿Por qué dice "Ruta no encontrada"?

R: Accediste a una URL inexistente. Usa el menú de navegación para moverte por la aplicación.

SECCIÓN II: DOCUMENTACIÓN TÉCNICA

Arquitectura General

Componente Versión Propósito
Angular 20.2.0 Framework principal SPA
TypeScript 5.9.2 Lenguaje tipado
Bootstrap 5.3.8 Diseño responsivo
Firebase 12.13.0 Backend y Autenticación
RxJS 7.8.0 Programación reactiva

Estructura de Proyecto

tienda-online/
├── src/app/
│   ├── [componentes]/           # Componentes Angular
│   ├── servicios/               # Servicios (Firebase, Login, etc.)
│   ├── models/                  # Modelos de datos
│   ├── app.routes.ts            # Definición de rutas
│   └── app.ts                   # Componente raíz
├── public/                      # Archivos estáticos
├── firebase.json                # Config Firebase
├── package.json                 # Dependencias
└── angular.json                 # Config Angular CLI

Sistema de Rutas

Ruta Componente Protegida
/ InicioComponent Sí
/login Login No
/listado-productos ListadoProductos No
/agregar FormularioProducto No
/editar/:llave FormularioProducto No

Servicios Principales

Firebase Service

Inicialización y configuración de Firebase. Proporciona instancias de Auth y Firestore.

Login Service

Gestión de autenticación, tokens y estado de sesión. Métodos: login(), logout(), isAuthenticated()

Datos Service

Operaciones CRUD con la base de datos. Sincronización de datos en tiempo real.

Guardian Service

Route Guard que protege rutas según estado de autenticación.

SECCIÓN III: DESARROLLO

Configuración del Entorno

Requisitos:
  • Node.js: v18.19.0 o superior
  • npm: v9.0.0 o superior
  • Git v2.0.0 o superior
  • Visual Studio Code (recomendado)
Instalación:
npm install
npm start
# Acceder a http://localhost:4200

Crear Componentes

Usar Angular CLI:
ng generate component nombre-componente

Esto crea automáticamente:

  • nombre-componente.ts - Clase
  • nombre-componente.html - Template
  • nombre-componente.css - Estilos
  • nombre-componente.spec.ts - Tests

Testing

Ejecutar Tests:
npm test

Abre Karma en el navegador y ejecuta los tests unitarios.

Cobertura:
npm test -- --code-coverage

Build y Deploy

Desarrollo:
npm start
# Puerto: http://localhost:4200
Producción:
npm run build
# Output: /dist/tienda-online/
Deploy Firebase:
npm run build && firebase deploy

Mejores Prácticas

HACER:
  • Separar lógica en servicios, presentación en componentes
  • Usar TypeScript con tipado estricto
  • Reutilizar componentes y servicios (DRY)
  • Escribir tests unitarios
  • Documentar código complejo
NO HACER:
  • Lógica compleja en componentes
  • Olvidar desuscribirse de Observables
  • Nombres de variables no descriptivos
  • Ignorar errores silenciosamente
  • Hardcodear valores de configuración

Comandos Útiles

Setup e Instalación
npm install
npm start
npm run build
Testing y Quality
npm test
npm run lint
ng build --prod
